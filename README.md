# Lakony Emmanuel — Software Engineer

An interactive portfolio built with **plain HTML, CSS, and JavaScript**. No frameworks, build tools, database, or backend required.

## Files

- `index.html` — accessible HTML and site content
- `styles.css` — layout, animation, dark/light themes, blue accents, and responsive styling
- `script.js` — navigation, project details, keyboard shortcuts, filtering, themes, and inquiry form

## Run locally

Open `index.html` in Chrome, Edge, or Brave. You can also use VS Code with the Live Server extension.

## Publish using GitHub Pages

Go to **Settings → Pages** in this repository. Under **Build and deployment**, select **Deploy from a branch** and choose **main** and **/(root)**; then save.

Once enabled and deployed, this project should be accessible at:

https://lakonyemma.github.io/portfolio/

*The URL is not confirmed live until GitHub Pages is enabled and the deployment completes.*

## Contact inquiries

The form currently **copies the inquiry text** and does not send email. To have it open an email draft, set `CONTACT_EMAIL` at the top of `script.js` to the contact address you choose to make public.

## Featured work

Project entries live in the `PROJECTS` array in `script.js`. Some projects are private or in progress. Preview illustrations in the portfolio are stylized artwork, not product screenshots.
